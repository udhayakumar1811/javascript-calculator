
# JavaScript Calculator

A simple and responsive Calculator built using HTML, JavaScript, and Bootstrap 5.

## Features

- Addition (+)
- Subtraction (-)
- Multiplication (*)
- Division (/)
- Number buttons (0-9)
- Clear button
- Input validation
- Responsive Bootstrap layout

## Technologies Used

- HTML5
- JavaScript
- Bootstrap 5.3.8

3. Open index.html in your browser.
